# Inbox

> Files that have arrived but are not filed into a folder yet: uploads, emailed attachments and receipts, and how to file, tag, rename or trash each one.
> **Route:** /dashboard/m/documents/inbox
> **Order:** 30

Open **Inbox** in the Documents menu. The line under the title reads `Captured but not filed yet — uploads and emailed attachments land here.` Everything here is waiting to be put in a folder. To add a file, click {button:Upload|outline|upload}. To put one away, open its menu and click `File into…`.

## What you see

- **Each row.** The file's title, or its file name. Under it, the size, such as `1.2 MB`, then `· from Receipts` for a receipt captured by Accounting, and its tags as chips. At the right, the date it arrived and its menu, {icon:more-horizontal}. Click the name and the file opens in this tab: a PDF, photo or plain text file shows, and any other kind downloads. Use your browser's back button to return.
- **The menu.** `Rename`, `File into…`, `Tags…`, `Upload new version…` and `Version history` for files uploaded here, and `Move to trash`. Each is described in [A file](file.md). A receipt has no version items.
- **What lands here.** Files uploaded from the Overview, the top of Browse or this page. Receipts emailed or uploaded to Accounting's own Inbox. A copy of an email message filed from Mail with no folder named, with its attachments. A file sent to a folder's email address goes straight into that folder, not here.

## How to file a file

1. Open the file's menu and click `File into…`. The dialog reads `Filing into an owners-only folder hides the file from staff.`
2. Pick the `Folder`.
3. Click {button:File|primary}. You see `Filed`, and the row leaves the Inbox.

Owners can also drag a file from the top of Browse onto a folder, which is the same Inbox.

## How to upload a file

1. Click {button:Upload|outline|upload} and pick one or more files, up to 100 MB each.
2. Each goes up in turn. You see `File uploaded`, or `3 files uploaded`. See [Browse](browse.md) for the kinds of file accepted and the messages.

## Messages

| Message | What it means |
| --- | --- |
| `Nothing waiting. Uploads land here until you file them.` | Everything has been filed. |
| `[file name] looks like a file you already have` | The same file is already in the cabinet. It was uploaded anyway. |
| `Detach this file from its transactions before trashing it.` | A receipt attached to a bill, invoice, payment or bank transaction cannot be trashed from here. |

## Not on this page

Only the newest fifty unfiled files are shown here; the top of Browse shows the same files with {button:Load more|outline}. There is no drag and drop, no share link and no viewer on this page; open the file in Browse for those. A receipt trashed from here goes to the Receipts trash in Accounting, not to the Documents Trash.

## Who can do what

Owners and staff upload, file, tag, rename, version and trash. Accountants can open and download, and every other item answers `Accountant access is read-only — reviews, sign-offs and exports only.`
