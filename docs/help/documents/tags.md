# Tags

> The labels you put on files: making a tag, renaming one, deleting one, and how tags reach files and searches.
> **Route:** /dashboard/m/documents/tags
> **Order:** 50

Open **Tags** in the Documents menu. The line under the title reads `A shared vocabulary for the whole business. Renaming a tag updates it everywhere; only an owner can delete one.` A tag is put on a file from the file's menu, and a click on any tag shows every file carrying it. To make one here, type it in `New tag name` and click {button:Create|primary|plus}.

## What you see

- **`New tag name`** and **{button:Create|primary|plus}** at the top.
- **The list.** Every tag, in name order: the tag as {badge:As-built|outline}, its short form, such as `as-built`, how many files carry it, such as `3 files`, {button:Rename|ghost}, and, for owners, a {icon:trash}. The count is of files you can see, so an owner's count includes files in owners-only folders and a staff member's does not.

## How to make a tag

1. Type the name in `New tag name`, up to 50 characters, and click {button:Create|primary|plus} or press {kbd:Enter}. You see `Tag created`.
2. Put it on files from each file's `Tags…` menu. See [A file](file.md). Up to 30 tags on one file, and 200 in the business.

`As Built`, `as-built` and `as built` are the same tag, because the short form is what a file carries.

## How to rename a tag

1. Click {button:Rename|ghost}. The dialog is `Rename tag` and reads `Only the display name changes. Files keep their link to this tag, so nothing is re-filed and no search stops working.`
2. Change the `Name` and click {button:Save|primary}. You see `Tag renamed`. The short form stays as it was.

## How to delete a tag

1. Owners: click the {icon:trash} on the row. The dialog is `Delete [name]?` and reads `This removes the tag from 3 files. The files themselves are untouched, and this cannot be undone.`
2. Click {button:Delete tag|destructive}. You see `Tag deleted`.

## Messages

| Message | What it means |
| --- | --- |
| `No tags yet. Tags are a shared vocabulary for the whole business — “as-built”, “permit”, “signed”.` | None have been made. |
| `A tag with that name already exists.` | The same short form is already in the list. |
| `That tag name can't be used — it needs at least one letter or number.` | The name was only punctuation. |
| `That's the maximum number of tags.` | The business has 200. Delete one first. |
| `This changed since you opened it — reload and try again.` | Somebody else renamed or deleted the tag while your dialog was open. |

## Not on this page

Tags have no colors, cannot be merged, and are put on files one file at a time. Typing a tag's name into Search does not find the files carrying it; click the tag instead. Ask us if you need any of these.

## Who can do what

Owners and staff make and rename tags and put them on files. Only owners delete a tag. Accountants see the page, and each button answers `Accountant access is read-only — reviews, sign-offs and exports only.`
