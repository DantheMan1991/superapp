# Counting stock

> Walking the shelf and writing down what is really there, and the pattern in what keeps going missing.
> **Route:** /dashboard/m/inventory/counts
> **Order:** 30

Open **Inventory** and click `Counting`. The heading reads `The record and reality will disagree. Counting is how that gets discovered — and what keeps turning up is worth more than any single count.` To start one, click {button:Count stock|primary}.

Counting is the one part of Inventory everybody can do.

## What you see

- **{button:Count stock|primary}.** Opens the dialog that starts a count. Anyone can.
- **`What keeps happening · last 1 year`.** Every correction made in the last year, grouped by reason. This only appears once there has been one.
- **The counts table.** `Counted`, `Where`, `Who`, `Lines` and `State`. Click a date to open it.
- **`Where`.** The place counted, or `Everywhere` when the whole business was walked in one go.
- **`Lines`.** How many shelves were written down.
- **`State`.** {badge:Being counted|primary} while it is open, {badge:Posted|outline} once it has been reconciled.

## The pattern panel

`Reason`, `Times`, `Items` and `Cost`. Under each reason sits a line explaining what it is really for. `Shrinkage`, for instance, reads `Gone, and nobody knows where. The reason worth watching: a pattern here is usually vermin, spillage or a leaking bin.`

Under the table: `A reason once is an accident. The same one every month is worth walking out to look at — this pack has an opinion about the pattern and none at all about the cause.`

`Found by counting` is the reason posted counts write. The rest come from corrections made by hand on an {{item|lower}}'s own page, so this panel is about every correction, not only the ones counting found.

Stock that turns up costs nothing, so `Found` and `Found by counting` show a dash under `Cost`. Nobody paid for it.

## How to start a count

1. Click {button:Count stock|primary}. The dialog reads `Record what is actually on the shelf. Nothing changes until you post it, so you can walk the whole place first and reconcile at the end.`
2. Set `When`. It begins on today.
3. Type `Who` did the counting. Up to 200 characters, and you can leave it blank.
4. Pick `Where`. The help reads `Everywhere is the honest answer for counting the whole barn in one go.`
5. Add `Notes` if you want.
6. Click {button:Start counting|primary}. You see `Count started` and the count opens.

Take the count over an afternoon if you need to. Nothing changes until you post it.

## Messages

| Message | What it means |
| --- | --- |
| `Count started` | The count is open and you are on it. |
| `Nothing counted yet` | Nobody has counted anything yet. |
| `Check the details and try again.` | The date is not a real date. |
| `Something went wrong saving that.` | Something unexpected. Try again, and tell us if it keeps happening. |

## Not on this page

- A count cannot be deleted. One you start and abandon stays in the list as `Being counted` forever.
- The notes you type when starting a count are stored and never shown again anywhere.
- The list is not paged, filtered or searchable.
- The pattern panel always says `last 1 year`, whatever the numbers behind it.
- If you need any of this, ask us.

## Who can do what

Anyone can start a count, including staff and your accountant. Everything on this page works the same for everybody, except that the `When it is deducted` tab in the strip is only there for an owner.
