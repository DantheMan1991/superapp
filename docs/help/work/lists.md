# Lists

> How work is grouped, and the only thing that decides who can see it.
> **Route:** /dashboard/m/work/lists
> **Order:** 20

Open **Work** and click through to `Lists`. {button:Back to my work|ghost|chevron-left} takes you back. The heading reads `A list is how work is grouped, and the only thing that decides who can see it.`

## What you see

- **{button:New list|primary|plus}.** Makes another list.
- **One row per list**, the default first and then in name order. Each shows a colour dot, the name, and badges.
- **{badge:Default|secondary}.** The list every business starts with, called `Work`. Anything that does not say where it goes lands here.
- **{badge:Everyone in the workspace|outline}** or **{badge:Owners only|outline}.** Who can see it.
- **`archived`** after the name, on lists you have put away.
- **{icon:pencil}** to change a list, and an archive button beside it.

This is the only screen that shows archived lists. Everywhere else they are hidden.

## Who can see what

**A list is the unit of sharing, and there are exactly two answers.**

| Setting | What it means |
| --- | --- |
| `Everyone in the workspace` | Every owner and every staff member sees the list and all the work on it. This is what a new list starts as. |
| `Owners only` | Only owners see the list, and therefore only owners see any work on it. To everybody else it does not exist: not on this screen, not in a picker, not in a view, not in the daily digest. |

**Who work is assigned to has nothing to do with who can see it.** That is deliberate, so somebody covering a holiday can see what is waiting.

**Only an owner can restrict a list.** Staff see the choice greyed out, with `Only an owner can restrict a list.` underneath. That stops somebody making a list they would then be unable to see.

There is no per-person sharing and no invitations. If you want one piece of work hidden, it goes on an owners-only list.

## How to make a list

1. Click {button:New list|primary|plus}. The dialog reads `Visible to everyone in the workspace unless you restrict it.`
2. Type a `Name`, up to 80 characters.
3. Pick a `Colour`.
4. Set `Who can see it`, if you are an owner.
5. Click {button:Save|primary}. The dialog closes and the list appears.

There is no cancel button. Close it with the X, or Escape.

Nothing tells you it worked beyond the list appearing. That is normal here.

## How to change one

Click {icon:pencil}. The dialog reads `Changing who can see a list changes who can see its work.` Change the name, the colour or who can see it, then {button:Save|primary}.

**The default list can be renamed and recoloured** like any other.

## How to archive one

Click the archive button. It goes immediately, with no confirmation, and the row shows `archived`.

Archiving does **not** delete anything. The work stays, links to it keep working, and the list simply stops being offered when you file work. Click the button again to bring it back.

**The default list has no archive button at all**, because it is where work lands when nothing else is chosen.

Nothing on this screen deletes a list, and nothing deletes work.

## Messages

| Message | What it means |
| --- | --- |
| `Only an owner can restrict a list.` | You are staff. A new list will be visible to everyone. |
| `The default list cannot be archived.` | It is where unfiled work lands. |
| `You do not have access to do that.` | Your role cannot make this change. An accountant reaching it means a write got through from an old tab; the page itself no longer offers one. |
| `That work no longer exists, or you cannot see it.` | It has gone, or it is on a list you cannot see. |
| `Invalid input` | Usually a name longer than 80 characters. |
| `Something went wrong.` | Something unexpected. Tell us if it keeps happening. |

## Not on this page

- A list cannot be deleted. Archiving is how one goes away.
- There is no way to move the `Default` badge to a different list.
- There is no per-person sharing, and no way to share one list outside the business.
- Archiving asks for no confirmation.
- Nothing confirms a save. The dialog just closes.
- The colours are listed by their plain names, in lowercase.
- If you have no lists at all, the page shows an empty card with no explanation. Click {button:New list|primary|plus}.
- If you need any of this, ask us.

## Who can do what

Everyone can make a list, rename it, recolour it and archive it. **Only an owner can set a list to `Owners only`,** or change one back.

Staff never see an owners-only list at all, so it will not appear in this screen's list either.

**Your accountant reads this page and changes nothing on it.** A line under the header reads `Accountant access is read-only. You can see every list, its colour and who it is visible to, and nothing here can be changed.` There is no {button:New list|primary|plus}, and no edit or archive button on any row.
